一、likeshop 是什么
likeshop 是一家做开源商城/点餐系统的团队，产品线包括：

likeshop 商城系统（单商户/多商户）

likeshop 连锁点餐系统

likeshop 外卖系统

技术栈通常是 ThinkPHP + uniapp + Vue，官网和 Gitee 上能查到仓库和文档。它属于商业开源：代码开放，但有授权协议，商用通常需要买授权或保留版权。

二、“全开源”到底开在哪
部分	是否开源	说明
后端 PHP	通常开源	看是否含加密文件
uniapp 前端	通常开源	确认给的是源码不是编译包
管理后台	通常开源	Vue 源码
数据库	给 SQL	表结构是否完整
插件/直播/分账	可能收费	部分高级功能单独授权
重点验：

核心文件是否加密（vendor、application 里搜加密文件）

是否有远程授权回调

商用授权范围（单域名/多域名/可二开）

高级功能（分账、直播、多商户）是否额外收费

三、连锁点餐要重点验的模块
模块	验收点
总部/门店	权限、商品统/独、区域定价
订单	按门店分流、跨店核销
库存	总仓/门店、调拨
分账	是否走微信/支付宝分账，别二清
点餐	桌码、沽清、加菜、叫号、后厨打印
收银	补单、退款、小票打印机、钱箱、扫码枪
预约	桌位/时段预约还是排队取号
多端	微信/支付宝/抖音支付登录是否真跑通
四、likeshop 这类商业开源常见的坑
加密文件：号称全开源，核心逻辑加密，换服务器失效。

授权回调：远程验证，跑路后系统瘫痪。

高级功能收费：分账、直播、多商户单独卖。

抖音端缩水：能编译，支付/登录没对接。

文档滞后：版本更新快，文档跟不上。

社区版 vs 商业版：Gitee 上是简化版，完整版要买。

售后响应：个人开发者或小团队，更新服务不稳定。

五、验收清单
授权：商用授权范围？单域名/多域名/可二开？

开源范围：后端、前端、后台是否都给源码？有无加密文件？

框架版本：ThinkPHP 版本、PHP 版本、Vue2/Vue3？

uni-app：微信/支付宝/抖音支付登录是否真跑通？

连锁：总部+门店权限、商品统/独、订单分流、库存调拨？

分账：是否走官方分账？还是二清？

点餐：桌码、沽清、加菜、叫号、后厨打印？

收银：补单、退款、小票打印机、钱箱、扫码枪型号？

后门排查：搜 eval、base64_decode、异常外链、远程授权验证。

演示站：亲自跑总部建店 → 门店接单 → 点餐 → 支付 → 分账 → 退款 → 打印。

文档：部署教程、数据库字典、接口文档、多端发布说明。
